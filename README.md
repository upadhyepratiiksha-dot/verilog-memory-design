# Memory Design — RAM & ROM

## Overview
This project implements and verifies fundamental memory structures in Verilog HDL, including synchronous RAM, asynchronous RAM, and ROM. Each module demonstrates core memory read/write behavior and timing characteristics, and is verified through dedicated Verilog testbenches.

## Features
- Synchronous RAM with clocked read and write operations
- Asynchronous RAM with combinational read and clocked write
- ROM with pre-initialized memory contents
- Modular, reusable RTL design for each memory type
- Functional verification using individual testbenches per module

## Tools Used
- Verilog HDL
- Xilinx Vivado
- ModelSim (or your simulator)
